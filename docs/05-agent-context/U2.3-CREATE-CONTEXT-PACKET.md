## 1. Objective

تنفيذ شريحة **U2.3 Create** كـFrontend-first vertical slice مكتملة وقابلة للتحقق، بحيث ينتقل المستخدم من brief Guided/Fast إلى بنية ومخرج قابل للتحرير، ثم يراجع البدائل ويحفظ نسخة أو يستعيدها، مع ثلاث compositions متخصصة: document وdeck وvisual concept؛ وكل ذلك بمحاكاة حتمية محلية وإيصال حقيقة واضح، دون Backend أو LLM أو image generation أو export إنتاجي.

- [ ] route `/{locale}/app/create` يقدّم Create composition فعلية، لا `prototype_service_workspace` عامًا.
- [ ] اختيار document/deck/visual concept ينتج state وartifact schema وsurface مختلفًا بوضوح.

- [ ] document يحقق block add/edit/delete/reorder وalternative accept/reject.

## 6. Domain contract to implement

### Stage machine

```text
crt_brief
→ crt_structure
→ crt_variants
→ crt_edit
→ crt_review
→ crt_version
→ crt_complete
```

A transition must come from a known deterministic event. No success merely because a timeout elapsed. A terminal run cannot restart; retry creates a new `run_` with `retryOf`.

### P0 compositions

#### Document

- title, outline, and editable text blocks.
- add/delete/reorder through visible buttons; never drag-only.
- at least one alternative section with accept/reject.
- read-only preview separate from edit state.

#### Deck

- at least 5 fixture slides.
- slide rail; title/body/notes edit.
- move up/down, duplicate, delete.
- guard against deleting the final slide.
- alternate slide selection cannot silently replace content.
- mobile shows one slide plus linear list.

#### Visual concept

- 4 local demo variants clearly labelled as demo assets.
- ratio/palette/concept labels and one selected variant.
- comparison surface describes differences beyond thumbnail.
- editable caption and alt text; alt required before ready.
- no crop/render/export claim.

### Version/storage rules

- states: `dirty`, `saving`, `saved`, `storage_failed`, `restored` as appropriate.
- every save after a saved version creates an `ArtifactVersion`.
- restore creates a new version based on the old version; it never erases history.
- branch/duplicate carries title and parent relation.
- failed storage exposes retry and does not claim saved.
- export preview has disclosure and no fake download.

### Fixtures and edge cases

```text
blank brief
invalid length
no variant
conflicting constraints
dirty navigation
storage failure
restored version
dense document/slides
long Arabic headings
mixed English brand name
missing image alt
```

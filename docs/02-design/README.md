مكان نظام التصميم والهوية وقواعد RTL/LTR والتفاعل والوصولية.

## الوثائق الحالية

- `COMPONENTS.md` — مخزون المكونات والvariants والحالات.
- `INTERACTIONS.md` — الاختصارات، overlays وfocus behavior غير المغطاة في عقد الحركة.

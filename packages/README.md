# الحزم المشتركة

الخطة الأولية:

- `ui/` — المكونات والتوكنز.
- `contracts/` — الأنواع ومخططات Zod وعقود الأحداث.
- `mock-api/` — handlers وfixtures للـFrontend prototype.
- `i18n/` — الرسائل والمصطلحات وإعداد RTL/LTR.
- `config/` — إعدادات TypeScript وlint وtest المشتركة.

لا تُنشأ حزمة قبل وجود استعمال فعلي لها.
